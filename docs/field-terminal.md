# 装备页网络看板：野外通信终端

样式只作用在网络状态卡。底板完全透明，正文白色、说明浅灰、槽号保留工业黄；字形使用近黑细描边，不另加整框。BOT 使用灰色短线和 BOT 字样。实测数值加粗，未知值不加粗，`整机网卡 · 非 P2P` 保留在标题。

使用原生水印字体（25），方向标签为正文 86%，次要信息为 90%，原生局部留白 3。底边、视差、出屏和退场行为沿用 1.1.6：不另建屏幕覆盖层，不强行吸附屏幕边缘。无入场动画、发光或闪烁。每个已占用栏只增两个无碰撞的静态顶线节点，随卡片销毁；没有水印模板时保留已有等待/诊断路径。武器命中分类不适用于网络看板。

预览图是根据生产格式化器和设计常量绘制的离线示意；四个样例并列对照不同状态，不代表同时存在两个本机，也不使用任何游戏截图或真实流量。
