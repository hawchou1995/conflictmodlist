# 1.1.6 装备大厅复测（待执行，不是实机通过记录）

用 `Survival` 打开装备页。已占用栏应随原生装备栏显示网络文字（含 BOT），空栏没有看板。移动鼠标、关闭并重开、局内按 `Esc`：检查文字不跳位、不重复。`[槽位网络]` 记录 `native-tmp/compare-row`（按钮行）或 `native-tmp/reference-row`（无按钮备用位置）、字形数 `glyphs` 和 `active`。若没有显示，对照 `waiting-equipment`、`waiting-watermark`、`waiting-button-row` 或完整异常；有字形仍需目视确认。

只有本机和 BOT 时，不应把整机网卡数值当作游戏流量。真人加入后再看几个采样窗口，区分游戏载荷、网卡、待采样和真实空闲；复测多人上报可用以下步骤。

1. **大厅零点击**：仅 B 安装，进入 A 的装备大厅，不点按钮。观察至少 15 秒，记下 B 的 HUD 截图：本机到可观测对端的 RTT、波动、收发及数据来源。有活动会话而持续全是占位：记为失败，保留插件版本、房主/客机身份、GTFO 与 BepInEx 版本。真实零值应区别于未提供值。
2. **合作但无房主插件**：C 安装相同 DLL 后加入。核对 B 与 C 上的本机行和队友报告行，方向与玩家相符，不出现由两个房主 RTT 推算的 B↔C 数值。离开/重进、另建新房：旧成员和旧报告不能当成当前值；观察空状态与恢复。
3. **每栏入口**：加入第四位真人，再用 BOT 替换一席。四名真人应各有一个「模组对照」、没有「网络」按钮；BOT/空位无入口。记录 16:9 与超宽各一张截图，特别看最右栏、长昵称和装 Localia 时；点每个入口都能辨认选中的人。检查没有挡住服装、装备或同栏其他控件。
4. **拖动与光标**：用能溢出的长清单。在关闭按钮、列表和轨道上移动，指尖应与命中一致。抓住滑块拖到底，横向移出轨道再松手；应能见最后一行，不触发后方装备。单格滚轮只滚一次；`Home/End/PgUp/PgDn`、`F`、点击关闭、`Esc` 和重开均有效。短清单无滑块。开着表切页/切出窗口，不应留拖动归属。
5. **弹窗和退场**：打开服装/装备选择，网络文字不能压住弹窗；离开装备页去主菜单，常显层和入口消失。无须提供任何 IP、Steam ID 或完整日志；把姓名打码，保留各行的角色、方向、单位和年龄即可。
